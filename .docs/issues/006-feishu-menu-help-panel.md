# Issue 006: Add a Deterministic Help Panel for Menu Commands

## Parent

.docs/prd/feishu-command-menu-card.md

## What to build

Add a help panel reachable from the first-level command panel. The help panel should explain the supported menu actions and text commands in a concise, deterministic card.

The help panel must be static code-generated content. It must not call an Agent, Codex, OpenCode, or any LLM.

## Acceptance criteria

- [x] The first-level help button opens a help card.
- [x] The help card lists the supported direct commands and second-level panels.
- [x] The help card explains that ordinary owner task text starts an Agent Turn, while opening the menu does not.
- [x] The help card content is deterministic and generated by code.
- [x] Opening the help panel does not call Bridge Core text command handling.
- [x] Opening the help panel does not start an Agent Turn or call any Agent/LLM client.
- [x] Tests use fakes or mocks and make no real Feishu, Codex, OpenCode, or LLM calls.
